# DaoDeca

DaoDeca-Engine utilizes Cloud-based architecture and Real-time processing for Distributed-Processing, enabling Auto-Scaling on the DaoDeca-Platform.

The key benefits of using DaoDeca include:

- DaoDeca-Engine utilizes Cloud-based architecture and
- Real-time processing for Distributed-Processing, enabling
- Auto-Scaling on the DaoDeca-Platform

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DaoDeca.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure DaoDeca, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
